# Known escapes

Defect patterns that passed a `task-verifier` PASS and were later confirmed
real by CodeRabbit on a pull request. `task-executor` checks its change
against this list before committing; `task-verifier` checks each commit
against it under layer 6. `coderabbit-review` appends a line whenever it
fixes a confirmed finding whose pattern is not here yet.

One line per pattern, under a `##` section for its category:
`- **category** — what goes wrong — PR <n>`. Keep it to patterns, not
individual bugs; merge a new instance into an existing line by adding its PR
number.
